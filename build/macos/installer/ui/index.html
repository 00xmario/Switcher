      Why macOS asked first
      
    
      macOS opens a downloaded app with a simple “Open” only when its developer is in Apple's Developer Program, $99 a year, and has each build notarized, scanned by Apple. Switcher is free and open source and isn't, so macOS wanted you to approve it in System Settings.
      
    
      Open Anyway let this installer run, once. It changed no settings on your Mac.
      
    
      You won't be asked again. The installer removes macOS's download flag from the Switcher it installs, and new versions arrive through Switcher's own updater, which macOS does not flag.
      
    
      
      
      Open sourceEvery line is on GitHub.
      
      
      Built in publicGitHub builds each release and attests to where every file came from.
      
      
      Signed releasesThe updater and the install script check Switcher's own signature.
